# 🎓 Personalized AI Learning Tutor

🧠 An intelligent learning assistant that personalizes learning paths, explains concepts, evaluates quizzes, identifies knowledge gaps, and recommends what learners should study next.

## ✨ Key Features

- 👤 Personalized learner profiles and goals
- 🧭 Adaptive learning path recommendations
- 📚 AI-assisted lesson explanations and examples
- 📝 Quiz generation and answer evaluation
- 📊 Learner progress tracking
- 🔁 Personalized revision and practice recommendations
- 🗓️ Weekly study plans
- 🧠 LLM integration and Retrieval-Augmented Generation (RAG)
- 📤 Exportable learning progress reports

## 🧰 Technology Stack

- 🐍 Python
- 📓 Jupyter Notebook
- 🧠 Generative AI and LLMs
- 📚 Retrieval-Augmented Generation (RAG)
- 📊 Learning analytics
- 🌐 Streamlit or React (future enhancement)

## 🚀 Project Objective

Develop an AI tutor that adapts educational content and study recommendations to learner goals, current knowledge, and assessment performance.

## 🗺️ Future Enhancements

- 🤖 LLM-powered tutoring conversations
- 📚 RAG over educational documents
- 🔁 Spaced repetition and mastery tracking
- 🌐 Interactive web application
- 🗄️ Persistent learner profiles
- 📊 Learning analytics dashboard

## 💼 Resume Description

Built a personalized AI learning tutor prototype that recommends learning paths, presents lesson cards, evaluates quizzes, identifies skill gaps, generates study plans, and tracks learner progress, with an extensible architecture for LLM tutoring and RAG.
